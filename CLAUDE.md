# CLAUDE.md — ai-chatbot-rag

## Project
Barbados immigration RAG chatbot — "Echo". Started as a coursework project, since extended with agent tools and a scraped knowledge base; now maintained as a portfolio project.
Streamlit UI, OpenAI Python SDK, FAISS vector store, OpenAI function calling, scraped immigration knowledge base.
Runs locally, single-user by design — see "Scope and Limitations" in README.md.

## Stack
- Python 3.14.3
- Streamlit (UI)
- openai SDK (chat completions + embeddings)
- FAISS (local vector store)
- pdfplumber (PDF parsing)
- python-docx (DOCX parsing)
- tiktoken (token counting)
- python-dotenv (API key loading)
- Pillow (avatar image generation)
- requests + beautifulsoup4 (web scraping)

## Design Principles
- Minimize API calls: cache embeddings by file hash, skip re-embedding unchanged files
- Token efficiency: pair-based history trimming (drops oldest user+assistant together) with tiktoken
- Dual-index retrieval: base index (k=4, prebuilt immigration knowledge) + user index (k=2, uploaded file)
- Tool-calling loop: model may call tools zero or more times before final response; loop exits on non-tool response
- Semantic chunking: paragraph-aware, tracks section headings, falls back to fixed-size for oversized paragraphs
- Defensive ingestion: parse errors caught explicitly; empty-text files rejected before embedding
- Keep code readable and explainable — the written docs in docs/ are part of the deliverable
- Bounded tool loop: MAX_TOOL_TURNS caps tool rounds, then forces a final answer with tools withheld
- Lookups over retrieval: country visa status comes from a parse of visa_requirements.txt, not embedding search — a flat list of ~25 country names embeds as a blur and misses individual countries
- Currency safety: assistant markdown passes through md_safe() so BDS$/US$ figures are not parsed as inline LaTeX by Streamlit
- User-facing failures surface via st.error — no raw tracebacks in the UI

## Conventions
- No LangChain — keep dependencies minimal and logic explicit
- Only `from openai import OpenAI` — do not add `import openai` (redundant)
- All OpenAI calls go through config.py client singleton (CHAT_MODEL=gpt-4o-mini, EMBED_MODEL=text-embedding-3-small)
- Streamlit session_state keys: history, conversation_id, base_chunks, base_index, user_chunks, user_index, ingested_file, starter_used
- Sidebar avatar embedded as base64 PNG in markdown HTML (not st.image) to allow CSS centering
- Echo chat avatar: periwinkle purple circle with white 4-pointed star (PIL-generated)
- User avatar hidden via CSS — message only, like Claude/ChatGPT
- Notebook cell 9 rag_chat() returns a new history list — does not mutate the input
- Do not push faiss_index/, conversations/, or uploads/ to git

## UI — Echo
- App name: Echo — Barbados Immigration Assistant
- Theme: deep Caribbean navy base (#0D1B2A)
- Orbs: 6 animated CSS orbs — 3 blues (#0EA5E9, #1D4ED8, #0369A1), 2 golds (#D97706, #F59E0B), 1 teal (#0F766E)
- Orb animation: multi-step keyframes (0/30/70/100%) with translate + scale + rotate + opacity breathing; 8s–19s cycles
- Chat bubbles: pill shape (border-radius: 999px), teal tint for user, amber-gold tint for assistant
- Sidebar: dark navy glass (rgba(8,18,30,0.78)), teal glow border, avatar + "Echo" (glowing) + "Immigration Assistant" label
- Echo title lives in the sidebar, not the main area — collapses naturally with sidebar
- Input bar: frosted white pill, dark navy text
- Bottom fade mask: 160px gradient dissolving content before input bar
- System prompt: structured reasoning is internal — no ASSESS/ANALYSE/REASON/RECOMMEND labels in output
- Starter prompts: 4 pills on welcome screen, teal glass style

## Knowledge Base
- 16 scraped pages from immigration.gov.bb and visitbarbados.org (run scraper.py to refresh)
- visa_requirements.txt: country-by-country entry requirements from MFA PDF (revised May 09, 2025)
- immigration_guide.txt: plain-language 10-section guide synthesised from all official sources
- Total: 132 FAISS chunks across 18 sources
- Rebuild index: python scraper.py && python build_index.py
